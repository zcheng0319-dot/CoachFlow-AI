# CoachFlow AI

AI-native CRM & Operations Copilot for sports training businesses.

## Status

Early product prototype.

## Development

Local-first development. Core business logic will be implemented and validated locally before cloud deployment.

## Data

Business records used during prototyping are synthetic demo data and must not be presented as real customer data.

## 当前原型

当前本地原型已包含模拟的少儿乒乓球培训业务数据、FastAPI 接口、确定性课程推荐、确定性线索评分，以及面向三 Agent 架构的 OpenAPI 工具契约。中文业务知识源已准备，用于后续 Coze RAG 检索。L2 CRM 写操作采用 Human-in-the-loop，创建跟进任务前需要用户确认。
